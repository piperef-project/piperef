Pipe rack widthLayout practice using pipe and flange OD

Formula used

Line envelope: env = max(OD/2 + ins,  F/2 + ins if flanges insulated)
Neighbours: cc = max(OD/2 + ins + OD′/2 + ins′ + 25,  flange + OD′/2 + ins′ + 25), rounded up to 10 mm
Tier width = 300 (column) + 2 × 100 (edge) + env(first) + env(last) + Σ cc along each side + cc between the two inner lines
Future = tier width × f, rounded up to 100;  rack width = largest tier + future, rounded up to 500 (column C/C)
Tier spacing = max(1500, largest line envelope incl. shoe + 750, rounded up to 250)
Trays: 300 + 200 + n·w + (n − 1)·150 per group, + 300 between electrical and instrument

Worked example

Two process lines on one tier: NPS 8 Class 150 with 40 mm insulation, NPS 6 Class 300 bare. Flanges insulated, 25% future, no trays.

  1. Line 1: OD 219.1, flange OD 342.9 → env = max(109.6 + 40, 171.5 + 40) = 211.5 mm
  2. Line 2: OD 168.3, flange OD 317.5 → env = 158.8 mm
  3. cc = max(109.6 + 40 + 84.1 + 25 = 258.7, 211.5 + 84.1 + 25 = 320.6, 158.8 + 149.6 + 25 = 333.3) = 333.3 → 340 mm
  4. Tier = 300 + 200 + 211.5 + 158.8 + 340 = 1210.2 mm (one line next to each column)
  5. Future = 1210.2 × 25% = 302.6 → 400 mm; total 1610.2 → rounded up to 2000 mm

Result: Rack width 2 000 mm column C/C.

Units

  • mm throughout; elevations in mm from grade

Standard or engineering basis

  • Pipe OD: ASME B36.10M; flange OD: ASME B16.5 (NPS ≤ 24) and B16.47 Series A (NPS 26–48)
  • Line arrangement and allowances follow common EPC pipe rack practice (largest lines at the columns, future space in the middle, utilities above process, flare at the top outside). They are not code requirements.

Assumptions and limitations

  • A first-pass width for layout studies, not a structural design.
  • Clearances (25 mm), column width (300), edge (100) and tray gaps (150) are typical values; use your project standard.
  • Line loads, beam sizes, branch connections, valves on the rack, expansion loops and access are not checked.
  • Flanges on neighbouring lines are assumed staggered.
