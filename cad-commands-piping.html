Piping workflows

Isometric drawings

  1. ISODRAFT (AutoCAD) or SNAP → Style → Isometric (BricsCAD) to start
  2. F5 or Ctrl+E to switch between left, top and right planes
  3. ELLIPSE → Isocircle for round items on the iso planes
  4. DIMALIGNED for dimensions along the pipe runs
  5. MLEADER for line numbers and weld or support callouts

P&ID drafting

  1. INSERT valve and instrument blocks (the Pipe Ref P&ID symbols download as DXF blocks)
  2. ATTEDIT to fill in tag numbers; BATTMAN and ATTSYNC to fix block attributes
  3. MATCHPROP to bring lines onto the right layer and linetype
  4. LAYISO to check one service or line type at a time

Counting for a take-off

  1. BCOUNT and press Enter: counts every block in the drawing
  2. COUNT palette in AutoCAD 2022 and later
  3. QSELECT by block name and layer, then read the count
  4. DATAEXTRACTION (DX) to send block names and attributes to Excel

Cleaning a client drawing

  1. AUDIT to fix errors, or RECOVER if it will not open
  2. PURGE (PU) to remove unused layers and blocks
  3. OVERKILL to delete duplicate lines
  4. XREF to check missing references; bind only what you must send
  5. LAYISO / LAYUNISO to check what sits on each layer

Turning a PDF into CAD

  1. PDFATTACH to see it first, or PDFIMPORT to convert it
  2. DIST on a known length, then SCALE with the Reference option to fix the scale
  3. TXT2MTXT to join broken text, OVERKILL to remove doubled lines
  4. PURGE to clear the imported clutter

Editing tags in Excel

  1. ATTOUT and pick the tagged blocks: valves, instruments, line numbers
  2. Open the text file in Excel, change the values, save as tab-delimited text
  3. ATTIN to load the changes back into the drawing
  4. TCOUNT to number new tags in sequence

Command not working?

The command line has disappeared

In AutoCAD press Ctrl+9 or type COMMANDLINE. In BricsCAD, right-click a toolbar or the ribbon and tick Command line.

Snaps do not catch points

Press F3 to turn object snap back on, and type OSNAP to choose which snaps are active.

Each pick replaces the previous selection

Set the system variable PICKADD to 1 (or 2). With 0 you must hold Shift to add objects.

Open and Save show prompts instead of a window

Set FILEDIA to 1.

An alias like L or CO does nothing

Someone edited the alias file (acad.pgp in AutoCAD, default.pgp in BricsCAD). Restore it, then type REINIT in AutoCAD.

The drawing is slow and heavy

Run AUDIT, PURGE and OVERKILL, and check for big xrefs or images.
