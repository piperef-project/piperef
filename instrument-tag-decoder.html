Instrument tag decoder

Type an instrument tag from a P&ID, like FIC-101, PDIT-2034A or LAHH-3301, and read what each letter means, the loop number, and what the piping designer has to allow for. Letters follow the ISA-5.1 identification scheme.

Try:

How a tag is built

10-Unit or areaOptional
PDITLettersP pressure, D differential, I indicating, T transmitter
-2034Loop numberShared by every item in the loop
ASuffixOne of a pair, A and B

The first letter is what is measured. An optional second letter changes it (D = differential, Q = totalised). The letters after that say what the instrument does, in the order indicator/recorder first, then the output. All instruments in one control loop share the loop number, so FT-101, FIC-101 and FCV-101 belong together.

Instrument bubbles

The shape says what kind of device it is: a circle for a standalone instrument, a circle in a square for a DCS display or control, a hexagon for a computer function and a diamond in a square for a PLC. No line means the device is in the field. A solid line means it is in the main control room, where the operator can reach it. A dashed line means it is behind the panel or in a rack the operator does not normally use.

Letter meanings follow the ISA-5.1 identification letters, summarised in our own words. Many projects add their own tags (SDV, BDV, MOV). The project legend sheet always wins.
